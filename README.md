# 🎬 Netflix Landing Page

A Netflix-inspired landing page built using **HTML and CSS**. This project recreates the look and feel of Netflix with a visually appealing hero section, movie thumbnails, and a dark-themed interface.

## 🌐 Live Demo

**[View Netflix Landing Page](https://abhishek3012-ab.github.io/netflix-landing-page/)**

## 📌 Project Overview

This project is a front-end web development project inspired by Netflix. It demonstrates the use of HTML and CSS to create a modern streaming-platform landing page.

## ✨ Features

- 🎥 Netflix-inspired user interface
- 🌑 Dark-themed design
- 🖼️ Hero section with a background image
- 🎞️ Movie and show thumbnail images
- 📱 Responsive design, if supported by the implementation
- 🎨 Custom styling using CSS

## 🛠️ Technologies Used

- **HTML5** – Structure of the webpage
- **CSS3** – Styling, layout, and visual design

## 🚀 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/abhishek3012-ab/netflix-landing-page.git
   ```

2. Open the project folder:

   ```bash
   cd netflix-landing-page
   ```

3. Open `index.html` in your browser.
